# 参考项目与许可

本项目从零实现，以下开源项目只作为设计参考。我们借鉴的是思路和产品形态，没有复制它们的代码。

| 项目 | 参考了什么 | 许可 | 使用方式 |
| --- | --- | --- | --- |
| open-mercato | 多租户与组织层级、自定义角色和功能权限、按租户启用的动态模块 | 核心开源；`@open-mercato/enterprise` 为商业许可 | 仅参考设计；商业部分不阅读、不使用 |
| paperclip | "AI 公司"式的智能体组织：岗位与汇报关系、心跳唤醒、任务领取、预算上限、人工审批 | 开源（以其仓库 LICENSE 为准） | 仅参考设计，以 .NET 重新实现 |
| hindsight | 智能体长期记忆的组织方式（后续知识与记忆模块参考） | 开源（以其仓库 LICENSE 为准） | 仅参考设计 |
| dify | 模型供应商抽象、对话与工作流产品形态 | 带附加限制条款的开源许可 | 仅参考设计，不复制代码 |
| twenty | CRM 的数据模型与工作台交互 | AGPL-3.0 | 仅参考设计，不复制代码 |
| erpclaw、relaticle、daedalus-crm、Aexus、kelivo | ERP/CRM 功能范围、移动端对话体验 | GPL / AGPL 系 | 仅参考设计，不复制代码 |

原则：

- GPL / AGPL 及带附加限制条款的项目只看文档和产品行为，不复制、不改写其源代码。
- 商业许可的代码不阅读。
- 引入新的第三方依赖前确认许可兼容（优先 MIT / Apache-2.0 / BSD）。
